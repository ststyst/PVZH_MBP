# 战斗结算规则

本文件描述玩法层面的具体结算顺序，不讨论伪代码语法。伪代码写法见 `EffectDsl.md`。

## 胜负与终止

- 任意一方英雄生命值降至 0 或以下时，立即判定胜负
- 胜负一旦产生：
  - 立即停止后续事件触发
  - 停止后续攻击、伤害、治疗、召唤、出牌与效果连锁
  - 不再结算亡语、额外攻击、光环刷新等后续效果
- `play_card` 在胜负产生后直接失败
- `advance_phase` 在胜负产生后不再推进阶段
- 已开始的伤害动作会在英雄死亡后立即返回，不继续后续命中

## 攻击形式

| 词缀 | 行为 |
|---|---|
| 先攻 `first_strike` | 每个攻击整轮只触发一次，先对敌方英雄造成数值伤害；双重打击、三连打、狂热追加、穿透都不会让它重复触发 |
| 双重打击 `double_strike` | 第一次完整攻击动作与死亡结算后仍存活，再执行一次完整攻击动作 |
| 三连打 `triple_strike` | 一次攻击动作依次攻击左列、自身列、右列；列不合法则跳过；每列是独立攻击 |
| 穿透 `strikethrough` | 单次攻击命中当前攻击列全部敌方实体，并命中敌方英雄；三连打时三列分别穿透各自列 |
| 溅射 `overshoot` | 主攻击后对攻击者所在列左右相邻列的**敌方实体**造成数值伤害；不伤害友方 |
| 狂热 `frenzy` | 单次攻击击杀被命中的敌方实体后，追加一次完整攻击动作；穿透击杀也会触发 |
| 反伤 `thorns` | 被普通单体攻击命中时，对攻击来源造成数值伤害；不是攻击，不改变攻击形式 |

## 三连打与穿透

- 三连打会分别以左列、自身列、右列为 `attack_column`
- 穿透使用该次攻击的 `attack_column`
- 因此三连打 + 穿透 = 左列穿透、自身列穿透、右列穿透
- 穿透不会因为三连打而重复命中同一列

## 事件顺序

单次攻击大致顺序：

1. 额外攻击事件（仅强制攻击/狂热追加）
2. 先攻英雄伤害（每个攻击整轮一次，不随双打/三连/狂热/穿透重复）
3. 主攻击/穿透/溅射伤害
4. 反伤（仅普通单体攻击）
5. `attack` 事件
6. `attacked` 事件
7. 狂热追加攻击
8. 死亡结算

### `attacked`

- 普通单体攻击：被选中的实体仍存活时触发
- 穿透：每个被穿透命中的敌方实体分别触发
- 三连打：每列目标分别触发
- 溅射：不会为溅射目标触发
- 反伤：不触发

### `damaged`

- 只有最终伤害 > 0 时触发
- 隐形、防御减伤、无敌、锦囊免疫等全部结算后判定
- 致命同样要求最终伤害 > 0

### `extra_attack`

- 强制攻击触发一次
- 狂热追加触发一次
- 双重打击第二次不触发
- 三连打本身不额外触发；额外攻击中只在第一击前触发一次

## 墓碑

- 墓碑内实体不会受到伤害，也不会成为普通实体锦囊目标
- 仍可被 `destroy`、`remove_entity` 和墓碑专用能力处理
- 揭示时先移除 `buried`，再结算 `frozen_tombstone`，再触发 `tombstone_reveal` 与 `enter`

## 生命值

- 生命值增益同时增加当前生命与上限，并触发 `healed`
- 生命值减益无视护盾、隐形、无敌，不触发 `damaged`
- 生命值减少后当前生命小于 1 时，即使有无敌也会死亡
- 治疗不能超过生命上限
