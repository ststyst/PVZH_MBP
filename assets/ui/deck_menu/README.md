# 牌组编辑下拉菜单素材

把透明背景 PNG 放到本目录，文件名必须为：

| 文件 | 对应按钮 |
|---|---|
| `add.png` | 编入（从待选择卡牌加入牌组） |
| `remove.png` | 移出（从已编入卡牌移除） |
| `info.png` | 信息（查看卡牌详情） |

建议：

- 32 × 32 px 或 24 × 24 px
- 透明背景
- 图形主体居中，四周留 1~2px 安全边
- 由 `scripts/ui/deck_editor.gd` 的 `ICON_ADD` / `ICON_REMOVE` / `ICON_INFO` 读取

缺图时菜单会自动回退为纯文字，不会报错。
