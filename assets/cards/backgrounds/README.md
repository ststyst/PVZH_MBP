# 卡牌背景素材（按稀有度）

卡面 = **稀有度背景图** + **卡牌外观图**（`cards.csv` 的 `art_path`）。

## 文件命名

放在本目录，文件名固定为稀有度 slug（与 `config.csv` 的稀有度对应）：

| 稀有度 | 文件名 |
|---|---|
| normal | `normal.png` |
| rare | `rare.png` |
| super rare | `super_rare.png` |
| legend | `legend.png` |
| unknown | `unknown.png` |

缺哪张就回退到默认纯色卡牌样式，不会报错。

## 尺寸参考

| 素材 | 建议尺寸 | 说明 |
|---|---|---|
| 卡牌背景 | **512 × 640 px**（4:5） | 可再出 1024×1280 高清版；9 宫格边距按 **32 px** 切（代码里 `CARD_BACKGROUND_SLICE = 32`） |
| 卡牌外观（`art_path`） | **768 × 512 px**（3:2） | 也可用 512×512；显示区域会按比例裁切（cover），主体放画面中心、四周留 8% 安全边 |
| 卡牌列表格子实际显示 | 160 × 200 px | 背景按比例缩小显示 |
| 详情弹窗卡面实际显示 | 约 320 × 480 px | 背景同样 9 宫格拉伸 |

建议背景图：四周是稀有度边框装饰，中间留半透明/深色区域放卡图与文字；
底部预留约 200 px（按 512×640 设计）给名称、描述与状态文字。
背景图本身要覆盖整张卡；如果希望中间透明露出底色，PNG 带 alpha 即可。

## 外观图（art_path）

`cards.csv`：

```csv
...,description,deck_includable,art_path
火球术,...,6 点伤害。,1,res://assets/cards/art/fireball.png
```

- 路径支持 `res://` 与 `user://`
- 留空则只显示稀有度背景
- 列表格子显示区域约 144×84（3:2 裁切），详情弹窗约 300×160
- 导入设置：PNG，sRGB；需要缩放清晰可开 Mipmaps
