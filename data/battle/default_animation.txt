# 默认动画伪代码（所有卡牌共用）
#
# 触发条件：某张卡自己的 animation 列（data/cards/official/cards.csv）为空，
# 或者那里的伪代码解析出错时，游戏会自动改用下面这份默认动画。
#
# 怎么改：直接编辑本文件（纯文本），保存后重新载入卡牌（重开战斗 / 刷新卡数据库）即生效。
# 语法说明见 docs/AnimationDsl.md；改动不需要碰任何脚本。
#
# 当前默认：攻击时快速贴到目标旁边 → 播自身 hit / 目标 hurt → 立刻归位。
# 注意 "hit" / "hurt" 需要你在 assets/animations/*.tres 里做出同名动画，
# 没有对应动画时会静默跳过（只剩位移效果）。

when attack:
    move_to(target, 0.06, -18, 0, "ease_in")
    play_animation(self, "hit", "whole")
    play_animation(target, "hurt", "whole")
    wait(0.02)
    move_back(0.06, "ease_out")
